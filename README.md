# ZephyrLoom

A simple ZephyrLoom Platform for Data streaming.

ZephyrLoom is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple ZephyrLoom Platform for Data streaming

## Technology Stack

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ZephyrLoom.git`
2. `cd ZephyrLoom`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ZephyrLoom, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
